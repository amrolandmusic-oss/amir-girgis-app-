# Amir Girgis — Android Music App

مشروع Flutter مبدئي لتطبيق الفنان Amir Girgis بتصميم داكن، وصورة الفنان، ومقطوعتين مضمنتين للتشغيل دون إنترنت.

- اسم التطبيق: Amir Girgis
- الأغاني المضمنة: «ألقيت بألواني وحبري» و«شوفلي حل»
- المشغل يستخدم just_audio ويدعم إعدادات التشغيل في الخلفية.
- توجد مهمة GitHub Actions جاهزة لبناء APK وإرفاقه كـ Artifact.

راجع `BUILD_AR.md` لخطوات بناء APK بالتفصيل.

**تنبيه:** البث أونلاين يحتاج روابط MP3 مباشرة عبر HTTPS تملك حق توزيعها. لا توجد استضافة مرفقة بالمشروع.
